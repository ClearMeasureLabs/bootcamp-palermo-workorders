# Lean loop (v30g)
Never: narration, subagents, MCP, git, gh, dotnet, the grep/glob/search/read tools (use Get-Context), reading scripts/terminal files, editing unrelated tests, merging. Output missing -> rerun once. Script fails for a reason outside your code -> reply `SCRIPT_FAIL: <last line>`, stop. Reply only the RESULT line (GREEN prints it); after it, no more tool calls (no todos, handoff files, get_mcp_tools).
1. `pwsh -NoProfile scripts/agent/Get-Context.ps1 -Issue N`: criteria, EXISTING files, a RECIPE (complete exemplar of this kind of change: copy its shape) and the likely edit target + sibling test (FULL = complete, never read; a long sibling test shows its last test + usings: append after it, don't read it). NEW names don't exist yet: never search for them; NEXT_SCRIPT = the DbUp file name to create. TEST SETUP/TESTS lines = helpers to reuse and tests that already touch these symbols. Need more? `Get-Context.ps1 -Find 'ExactType|regex'` (matching lines +2 context, capped) or `-File path` (big files show an outline; then `-File path:a-b`), never both; 2 extra calls max (a 4th prints LIMIT). After LIMIT, edit: never read files via shell (cat/sed/rg/Get-Content). Never re-read; never open docs/ or scripts/. Unsure? Edit anyway: Submit and CI name what's missing. If EXISTING already meets every criterion, change nothing: `RESULT=ALREADY_DONE <file:line>`. Never add a duplicate type. Keep an endpoint's response format unless the criteria say otherwise.
2. Change only what the criteria need, code + tests in few edits with the edit tool (never rewrite files via shell; keep their usings). New logic in a method with 4+ branches -> private helper.
3. `pwsh -NoProfile scripts/agent/Submit-Change.ps1 -Issue N -Branch B` (checks, publish, waits ~7 min). RISK/*FAIL/CHECKS=RED -> fix exactly what it names, rerun Submit. A FAIL that names nothing -> `SCRIPT_FAIL`, never dig. No GREEN/RED -> run WAIT_CMD until one. RED only in unrelated tests -> WAIT_CMD -ForceRerun once. PUBLISH_FAIL -> reply with it.
Traps: CRAP max CC 6; every new method needs a unit test; new query/command needs a validator + test. Qodana: no unused usings (implicit usings cover System, System.Linq, System.Collections.Generic, System.Threading.Tasks), no namespace-qualified type names (add a using), no `?.`/`??` on non-nullable, `[a, b]` not `new[] {}`, bUnit ClickAsync not Click, new option props copy the ReSharper AutoPropertyCanBeMadeGetOnly line, new Core/Model `{ get; set; }` props get `// ReSharper disable once PropertyCanBeMadeInitOnly.Global`; leave no unused members. New WorkOrder/query props must survive remoting: RemotableRequestTests fakes them via ObjectMother/BogusOverrides (a DateOnly prop needs a rule there like WorkOrder.DueDate). WorkOrder Number max 7. New anonymous API routes -> ApiPublicPathRules.PublicLeaves. Tests: NUnit+Shouldly, ObjectMother; capturing ILogger<T> for logs.
