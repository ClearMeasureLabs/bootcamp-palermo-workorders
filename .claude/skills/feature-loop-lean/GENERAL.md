# Lean loop (v18g). Small change, no template.
Never: narration, subagents, get_mcp_tools/MCP, git, gh run/api, reading scripts/terminal files, editing unrelated tests, merging. Workspace branch is meant to stay as is. If a command's output is missing, rerun it once as is. If a script fails for a reason not in your code (path, git ref, MSBuild project not found), reply `SCRIPT_FAIL: <its last line>` and stop; never debug scripts, git refs, terminal files or the PR. Reply: the RESULT line only.
1. `pwsh -NoProfile scripts/agent/Get-Context.ps1 -Issue N` prints the criteria, EXISTING candidate files and outlines (the issue's only source). At most ONE more call, `-Find 'ExactTypeName|Other'` (no -Issue). Never a third. Then read only the line ranges you edit plus ONE sibling test (by range). No other searching/reading; never read a file twice. If EXISTING code already meets every criterion, change nothing and reply `RESULT=ALREADY_DONE <file:line>`; never add a duplicate type.
2. Change only what the acceptance criteria need; don't refactor or extend callers. Edit code + tests in few writes. New logic in an existing method with 4+ branches goes in a private helper.
3. `pwsh -NoProfile scripts/agent/Submit-Change.ps1 -Issue N -Branch B`: risk check, unit tests, changed integration tests (SQLite), publish; waits up to ~7 min for CI; if no CHECKS=GREEN/RED was printed, run the printed WAIT_CMD. RISK/FAIL -> fix exactly that, rerun. CHECKS=RED -> fix named items, rerun Submit. PENDING -> run WAIT_CMD again. RED only in unrelated tests -> WAIT_CMD -ForceRerun once. NO_CHANGES -> see step 1. PUBLISH_FAIL -> reply with it.
Map (src/; tests mirror under UnitTests/ IntegrationTests/; NUnit+Shouldly; ObjectMother/BogusOverrides): Core/Model(+StateCommands), Core/Validation, Core/Queries + DataAccess/Handlers, Database/scripts/Update/NNN_*.sql (next number), UI.Shared/Pages|Components (bUnit), UI/Api/Controllers, UI/Server, McpServer/Tools, LlmGateway, Worker.
Traps: CRAP fails a method above CC 6 even fully covered; every new method needs a unit test. Qodana: no unused usings; bUnit: await ClickAsync/ChangeAsync, not Click/Change; `[a, b]` not `new[] {}`; new option props copy the ReSharper AutoPropertyCanBeMadeGetOnly line. New WorkOrder/remotable-query props must survive remoting (RemotableRequestTests, BogusOverrides). WorkOrder Number max 7 chars. Warnings are errors. Acceptance tests (CI only) check read-only layouts and past due dates. Description/Instructions max lengths differ. New anonymous API routes must be added to ApiPublicPathRules.PublicLeaves (UI/Server). No logger test package: use a small capturing ILogger<T>.
