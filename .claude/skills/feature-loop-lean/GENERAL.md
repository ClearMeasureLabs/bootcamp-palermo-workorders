# Lean loop (v17g). Small change, no template.
Never: narration, subagents, get_mcp_tools/MCP, git, gh run/api, reading scripts/terminal files, editing unrelated tests, merging. Workspace branch is meant to stay as is. If a command's output is missing, rerun it once as is. If a script fails for a reason not in your code (path, git ref, MSBuild project not found), reply `SCRIPT_FAIL: <its last line>` and stop; never debug scripts, git refs, terminal files or the PR. Reply: the RESULT line only.
1. `pwsh -NoProfile scripts/agent/Get-Context.ps1 -Issue N` prints the criteria + outlines of the types it names (the issue's only source; no `gh issue view`). If it says NO_TYPES or the outlines miss the code to change, ONE more call with `-Find 'ExactTypeName|Other'`. Then read only the line ranges you edit plus ONE sibling test (by range). No other searching/reading; never read a file twice.
2. Change only what the acceptance criteria need; don't refactor or extend callers. Edit code + tests in few writes. New logic in an existing method with 4+ branches goes in a private helper.
3. `pwsh -NoProfile scripts/agent/Submit-Change.ps1 -Issue N -Branch B`: risk check, unit tests, changed integration tests (SQLite), publish; prints WAIT_CMD. RISK/FAIL -> fix exactly that, rerun. CHECKS=RED -> fix named items, rerun Submit. Run WAIT_CMD until GREEN/RED (PENDING -> run it again). RED only in unrelated tests -> WAIT_CMD -ForceRerun once. PUBLISH_FAIL -> reply with it.
Map (src/; tests mirror under UnitTests/ IntegrationTests/; NUnit+Shouldly; ObjectMother/BogusOverrides): Core/Model(+StateCommands), Core/Validation, Core/Queries + DataAccess/Handlers, Database/scripts/Update/NNN_*.sql (next number), UI.Shared/Pages|Components (bUnit), UI/Api/Controllers, UI/Server, McpServer/Tools, LlmGateway, Worker.
Traps: CRAP fails a method above CC 6 even fully covered; every new method needs a unit test. Qodana: no unused usings; `[a, b]` not `new[] {}`; new option props copy the ReSharper AutoPropertyCanBeMadeGetOnly line. New WorkOrder/remotable-query props must survive remoting (RemotableRequestTests, BogusOverrides). WorkOrder Number max 7 chars. Warnings are errors. Acceptance tests (CI only) check read-only layouts and past due dates. Description/Instructions max lengths differ. New anonymous API routes must be added to ApiPublicPathRules.PublicLeaves (UI/Server). No logger test package: use a small capturing ILogger<T>.
