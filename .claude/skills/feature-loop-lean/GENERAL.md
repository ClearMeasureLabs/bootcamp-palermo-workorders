# Lean loop (v20g)
Never: narration, subagents, MCP, git, gh, dotnet, reading scripts/terminal files, editing unrelated tests, merging. Output missing -> rerun once. Script fails for a reason outside your code -> reply `SCRIPT_FAIL: <last line>`, stop. Reply only the RESULT line (GREEN prints it).
1. `pwsh -NoProfile scripts/agent/Get-Context.ps1 -Issue N`: criteria, EXISTING files, the likely edit target + sibling test (FULL = complete, never read). At most one more call with `-Find 'ExactType|Other'`. Read only line ranges you edit that weren't FULL; never re-read. If EXISTING already meets every criterion, change nothing: `RESULT=ALREADY_DONE <file:line>`. Never add a duplicate type.
2. Change only what the criteria need, code + tests in few writes. New logic in a method with 4+ branches -> private helper.
3. `pwsh -NoProfile scripts/agent/Submit-Change.ps1 -Issue N -Branch B` (checks, publish, waits ~7 min). RISK/*FAIL/CHECKS=RED -> fix exactly what it names, rerun Submit. No GREEN/RED -> run WAIT_CMD until one. RED only in unrelated tests -> WAIT_CMD -ForceRerun once. PUBLISH_FAIL -> reply with it.
Traps: CRAP max CC 6; every new method needs a unit test; new query/command needs a validator + test. Qodana: no unused usings, no `?.`/`??` on non-nullable, `[a, b]` not `new[] {}`, bUnit ClickAsync not Click, new option props copy the ReSharper AutoPropertyCanBeMadeGetOnly line. New WorkOrder/query props must survive remoting (RemotableRequestTests, BogusOverrides). WorkOrder Number max 7. New anonymous API routes -> ApiPublicPathRules.PublicLeaves. Tests: NUnit+Shouldly, ObjectMother; capturing ILogger<T> for logs.
